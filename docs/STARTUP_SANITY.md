# Startup & playable sanity

After **`PolyPets → ★ First-Time Setup`**, you should get a stable, playable vertical slice.

## Run this
1. Import Feel (optional)  
2. `PolyPets → ★ First-Time Setup (run this)`  
3. Optional: `PolyPets → ★ Startup Sanity Check`  
4. Game view **480×720** → **Play**

## What works (interactive)
| Control | Action |
|---------|--------|
| Tutorial | Welcome → name → Cat/Dog/Rabbit |
| Feed / Shop / Play / Clean / Décor | Care loop |
| ◀ Room / Room ▶ / Home | Room nav (Home = Living Room) |
| Settings | Opens stub panel (Coming soon features listed) |
| Pin (always on top) | Toggles desktop intent |
| Floor coins | Click spinning coins (max 10) |
| Minigames | Species signature games → coins |
