# Materials (locked v1 set)

**25 materials only.** Assign these to every greybox / prop / pet / food mesh.

Rebuild: Unity menu **`PolyPets → Materials → Rebuild Color Palette (25 mats)`**

Full swatches + hex: [`docs/COLOR_PALETTE.md`](../../docs/COLOR_PALETTE.md)

| Group | Mats |
|-------|------|
| House | Floor, Wall, Trim, Prop, Lamp, Rug, Shadow, Bowl, Metal |
| Pets | Cat×2, Dog×2, Rabbit×2 |
| Food | Budget, Medium, Super, Coin |
| Play | Leaf, Carrot, Water, Dirt, Fish, Sky |

Do **not** drop one-off `.mat` files here outside this list.
