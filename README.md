# PolyPets

A low-poly desktop Tamagotchi × idle clicker for PC: care for box-headed pets, earn currency, buy rooms, and play short minigames — all in a small always-on-top window.

## Docs

- **[Game Design Document](docs/GAME_DESIGN_DOCUMENT.md)** — vision, core loop, pets, rooms, economy, minigames, phased delivery
- **[Unity Setup](docs/UNITY_SETUP.md)** — URP project setup + editor bootstrap

## Unity quick start

1. Create a **Unity 2022.3+ / 6 URP** project (or merge this `Assets/` folder into one).
2. Menu: **PolyPets → Bootstrap Starter House Scene**
3. Play `Assets/Scenes/House_LivingRoom.unity` at **480×720**
